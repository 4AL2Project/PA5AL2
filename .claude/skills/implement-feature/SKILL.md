name: implement-feature
description: Implémente une feature
---

- Crée une branche dédié à la feature en partant toujours de la dev
- Pull et fetch la dev avant l'implémentation
- Implémente la fonctionnalité demandée
- Test le code produit
- Commit et push

Toute les actions doivent être effectuées en utilisant les skills si disponible.
